The walker lists tracked plus untracked-not-ignored files through `git ls-files --cached --others --exclude-standard`, falling back to its own directory walk outside a repository. The original rule was that one fixed exclusion set — node_modules, dist, build, .cortex, .git — applied on both paths. That rule is wrong for half of it: `dist` and `build` are a guess about generated output, and a git listing did not need a guess, because --exclude-standard already applied the project's own .gitignore, which is the authority on what is generated here. Applying the guess on top of it made a tracked `src/build/pipeline.ts` invisible to the index and to get_impact, with nothing reporting it — `computeDrift` reads the same filter, so doctor called the tree in sync.

The set is split. `NEVER_SOURCE` (node_modules, .cortex, .git) applies to both paths: a dependency tree and the two tool directories are never project source, whoever listed them. `PRESUMED_GENERATED` (dist, build) applies to the fallback walk alone, where there is no .gitignore verdict to defer to.

Replaces the original walker decision.
