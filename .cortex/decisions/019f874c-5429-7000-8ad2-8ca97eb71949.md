buildRuntime/CortexRuntime saíram de src/mcp/ para src/app/ — a CLI importava @/mcp/runtime em 8 arquivos, invertendo o modelo de dois frontends paralelos. Os casos de uso duplicados entre CLI e MCP foram extraídos para app/: search-decisions (busca exata + semântica), decision-impact (DEPENDS_ON + impacto por código com degradação para code_warning) e symbol-hints (sugestões did-you-mean). CodeImpactAnalysis migrou de storage/ para app/ (é regra de negócio, não persistência). CortexRuntime ganhou cortexDir e passou a depender da interface CodeIndex em vez da classe LazyCodeIndex. Escolhido um único diretório app/ (composition root + casos de uso juntos) em vez de runtime/ + app/ separados, pelo tamanho do código (~3,6k linhas). Rejeitados: hexagonal completo, pastas por feature e quebra do NodeRepository — sem justificativa no tamanho atual.
