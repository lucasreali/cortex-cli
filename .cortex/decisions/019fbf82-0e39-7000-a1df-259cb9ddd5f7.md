CLAUDE.md already said cross-directory imports use the @/ alias, but 27 imports in src/cli/commands and src/mcp/tools still climbed with ../, sixteen of them sitting directly beside @/ imports in the same block. Biome's organizeImports only sorts specifiers, it never rewrites them, so nothing enforced the rule.

style/noRestrictedImports now fails lint:ci on any specifier matching ../**. Two carve-outs are declared in biome.json overrides: src/version.ts (package.json sits above src/, unreachable through @/*) and src/embedding/onnxruntime-assets.ts (the package does not export ./dist/*, so the WASM files must be reached by path).

Descending imports (./commands/x, ./queries/z.sql) stay relative — the rule targets climbing only. tests/ gained a @tests/* tsconfig path so a helper in another test directory can be named the same way.
