CLAUDE.md now states the comment policy explicitly: judge whether a name can carry the meaning before writing a comment; write one only for a non-obvious external constraint or a deliberate trade-off. A review of all 81 comments found 70 already earned their place and none stale, so this codifies existing practice rather than changing it. The 19 SQL comments were the only Portuguese left and are now English.

Separately, CLAUDE.md claimed install.sh's detect_suffix and release/target.ts 'must keep agreeing' while install.sh emitted linux-x64-baseline, a suffix targetForHost could not produce, and probed musl through ldd where target.ts checked only loader paths. targetForHost gained both. RELEASE_SUFFIXES is now the one asset list, and install.sh's flow moved into an install function so CI can source it with CORTEX_SOURCE_ONLY=1 and compare the two on the runner.
