Busca cross-project é uma tool própria (e cortex search --all-projects), nunca dobrada nas tools escopadas — leitura escopada permanece escopada, lição do vazamento cross-project do protótipo. Não aceita projectPath (é global por definição) e devolve resultados agrupados e rotulados por projeto, jamais fundidos num ranking único: scores de stores diferentes não são comparáveis. Projeto que falha ao abrir entra em skipped com reason, success-shaped. Roots = registro persistente ∪ projeto atual. O fan-out reusa RuntimeRegistry.openRoot no MCP (runtimes cacheados, daemon compartilhado) e reconcile-on-open é aceito — só o prompt-hook é proibido de reconciliar.
