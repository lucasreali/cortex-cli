readRegisteredProjects used to rewrite ~/.cortex/projects.json whenever it filtered an entry out — a read that writes, and a destructive one. isInitialized() is an existsSync, which is also false for EACCES or an unmounted volume, so a read taken while a network share was down permanently deleted those projects; the rewrite was also last-writer-wins over a snapshot taken before the read, erasing a concurrent `cortex init`.

The read now filters and returns, and never touches the file: a store behind an unreachable mount is absent from that one answer and comes back on the next. registerProject is the only path that drops entries, and it drops only those ProjectRoot.isProvablyAbsent() confirms are gone — statSync raising ENOENT on both decisions.db and decisions/, not merely failing. Any other errno means unknown, and unknown means keep.

isProvablyAbsent is deliberately not the negation of isInitialized. The two answer different questions ("can I read this project right now?" versus "is this project gone for good?") and the second is the only one allowed to cause a deletion.
