O TsxExtractor roda queries tree-sitter separadas por kind: function_declaration, class_declaration, arrow nomeada (variable_declarator + arrow_function) e métodos capturados junto com a classe dona para gerar o nome qualificado 'Classe.metodo' (constructor vira 'Classe.constructor'). Export default anônimo não tem nome e fica de fora — a âncora nesse caso é o arquivo. Imports cobrem import_statement, export_statement com source (re-exports) e require() via predicado #eq?; import type também é indexado (inócuo e barato). Specifiers são deduplicados por arquivo porque a PK de imports é (from_path, specifier). A gramática TSX segue o padrão da fase 0 (release oficial v0.23.2, sha256 pinado, cache ~/.cortex/grammars) com um refinamento: cache corrompido é rebaixado e um download que falha o hash é apagado antes do throw.
