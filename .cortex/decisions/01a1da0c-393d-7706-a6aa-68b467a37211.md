Files stay immutable by convention, but they are markdown on a branch and people edit them: typo fixes, merge resolutions. The reconcile only ever imported unseen ids, so an edited file left title, body, anchors, FTS and vector stale while edges were re-derived — clones diverged. nodes.content_sha now records the bytes a row came from; the cheap path hashes every present file without parsing and rewrites the rows whose hash moved, dropping the vector only when title or body changed. A present file that stops parsing keeps its last edges, so a broken successor never revives its predecessor. Rejected: mtime (forged by any restore) and a full parse on every command.
