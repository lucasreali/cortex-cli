The extractor queried only function_declaration, class_declaration, variable_declarator+arrow and method_definition. Everything else came back as an empty symbol list: interfaces, type aliases, enums, abstract classes (a different node, so the class *and* every method on it), generators, ambient signatures, namespaces, class fields, `export const x = function(){}` and `export const C = React.memo(...)`. Two user-visible consequences: save_decision told the model the symbol did not exist, and anchor grading called it `unresolved`.

All of it is now extracted, plus dynamic `import()` and `import x = require()` as edges, and getters/setters carry distinct kinds so two accessors sharing a name and a line stop being indistinguishable rows.

Three queries, never one per pattern: `matches` walks the whole tree, so a query per kind would parse once and traverse twenty times. The capture name carries the kind instead. Declarations and members are deduplicated on (line, kind, name) — that pair is what tells a getter from its setter — and `variable` is a fallback kind that loses to any more specific pattern claiming the same (line, name), which is how `export const f = () => {}` stays an `arrow`.

Interfaces contribute their own name but not their members: an interface member is a type, where a class member is code a change can break. EXTRACTION_VERSION went to 3 for the whole of it.

Replaces the original TSX extraction decision.
