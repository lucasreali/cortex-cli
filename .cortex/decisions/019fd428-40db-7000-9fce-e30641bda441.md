Projetos se registram em ~/.cortex/projects.json (override CORTEX_PROJECTS_FILE) quando cortex init roda, quando withRuntime abre um runtime no CLI e quando RuntimeRegistry.open resolve um root no MCP — nunca dentro de buildRuntime, para testes in-process não tocarem estado global. O arquivo é cache por usuário reconstruível como models/daemon: corrupto lê como vazio, entradas cujo .cortex sumiu são podadas na leitura, escrita é atômica com last-writer-wins, e falha de registro é engolida (registrar nunca pode falhar um init ou uma busca). Fica em storage/ (precisa de ProjectRoot), não em support/, que permanece leaf sem dependências.
