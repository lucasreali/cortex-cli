The worker loaded weights and an ONNX runtime module from the model repository's main branch, so whoever moved that branch changed what every installed cortex executes; the revision is now a commit hash, and the residency marker carries it because pinning moves where transformers.js caches files (existing caches download once more). The first commit after init also fetched ~300 MB in a detached child with no output; the hook now skips the embed until the model is resident, and workers acquiring it take a lock so two never write one cache. Rejected: verifying file hashes ourselves (the pin already fixes the content).
