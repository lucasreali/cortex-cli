listSourceFiles usa 'git ls-files --cached --others --exclude-standard' (com core.quotepath=off) para respeitar o .gitignore cobrindo também arquivos novos ainda não commitados; fora de repo git, cai num walk recursivo. As exclusões fixas (node_modules, dist, build, .cortex, .git, > 1 MB) são aplicadas por filtro de segmentos depois da coleta, então valem igualmente para paths vindos do git (ex.: dist/ trackeado) e do walk. Arquivo trackeado mas apagado do working tree é ignorado via statSync throwIfNoEntry. Extensões mapeadas para a coluna lang: ts/tsx/js/jsx diretos, mts/cts→ts, mjs/cjs→js — TS/JS conforme escopo da fase 2, o resto degrada para âncora de arquivo.
