Bun.YAML.stringify emite estilo flow numa única linha ({title: x,keywords: [a,b]}), inútil para um diff revisável — que é o ponto da mudança inteira. Então o writer de frontmatter é block YAML escrito à mão (~30 linhas) e a leitura usa Bun.YAML.parse, que lê block YAML corretamente. Toda string é citada via JSON.stringify: JSON é subconjunto de YAML 1.2 e todo escape que ele emite é um escape legal de escalar entre aspas duplas, então isso é sempre correto e remove a tipagem implícita — uma decisão intitulada 'no' voltaria como o booleano false. A alternativa (citar só quando necessário) exigiria reimplementar as regras de escalar plano mais todas as colisões de tipo implícito, e seu modo de falha é um valor silenciosamente destipado. Ruído no diff não pesa aqui porque arquivos são imutáveis: todo diff é a adição de um arquivo inteiro.
