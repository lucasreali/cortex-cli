src/release/archive.ts gunzips with Bun.gunzipSync and walks the 512-byte ustar headers itself to pull the single member named cortex. Shelling out to tar was rejected on three grounds: the compiled binary's premise is having no runtime dependencies (busybox tar on Alpine has a different flag surface, and Alpine is a shipped target); a pure function reaches the 100% coverage bunfig.toml enforces, while asserting on tar's stderr means asserting on messages that differ between GNU tar and bsdtar; and extracting exactly one member by name to a path we chose makes path traversal from a hostile archive inexpressible. We own both ends of the format — package-release.ts writes ustar with a single member — and a test round-trips against an archive the real tar binary produced.
