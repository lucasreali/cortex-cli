ensureGitignore checked all three rules at once and, on any miss, appended all three again with a plain Bun.write. A file already holding two of them got a duplicate; worse, the rules are order-dependent and git resolves them last-match-wins, so appending `/.cortex/*` below an existing `!/.cortex/config` would stop the decisions from being tracked at all — the opposite of what the command promises.

planGitignore is now a pure function in src/install/gitignore.ts that answers one of three things. Everything present: satisfied. The exclusion present and only negations missing: append just those, which is safe because a negation below the exclusion is exactly where it belongs. The exclusion missing while a negation is already there: conflict — say which rules are missing and leave the file to the person who wrote it, because there is no position this can append them to that works. The write itself moved to writeAtomically, like every other file this project touches.

The rules are passed in rather than imported, which keeps src/install/ free of a dependency on src/storage/ and keeps the logic unit-tested in process, as the rest of that directory is.
