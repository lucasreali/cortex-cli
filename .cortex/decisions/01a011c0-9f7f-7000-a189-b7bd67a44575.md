Three unguarded I/O calls let one bad file abort the whole pass: statSync throws ELOOP on a symlink cycle and EACCES under an unreadable directory (throwIfNoEntry only suppresses ENOENT), readdirSync throws the same way, and the two content reads throw for a file that vanished between the listing and the read — the ordinary race against a checkout or an editor save. One chmod 000 file left a two-file repository with nothing indexed, and doctor died on the same call, since checkCodeDrift shares the walker.

Every one of those is now caught at the file it happened to: the walk collects SkippedSource entries, the pass adds its own read failures, and IndexReport.skipped carries them out to `cortex index` and `doctor`, which name the first five through cli/skipped-sources.ts. A skipped file is also never pruned from the index: it is a file the pass could not read, not a file that left the tree, so dropping its symbols over a transient permission error would be the worse answer.
