Na SemanticSearch, o embedQuery do intent corre contra timeout de ~2s; no estouro a resposta vem do FTS5 com source: 'fts' (o chamador sabe que foi degradado) e o provider segue carregando para a próxima query — o worker não é morto. Cobre o cold start pós-idle-kill (§2.4): o vetor nunca é caminho bloqueante de uma tool call.
