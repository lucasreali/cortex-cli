O extractor consultava só function_declaration, class_declaration, variable_declarator+arrow e method_definition. Todo o resto voltava como lista vazia de símbolos: interfaces, type aliases, enums, classes abstratas (nó diferente, então a classe *e* cada método dela), generators, assinaturas ambient, namespaces, campos de classe, `export const x = function(){}` e `export const C = React.memo(...)`. Duas consequências visíveis: save_decision dizia ao modelo que o símbolo não existe, e a graduação de âncora chamava isso de `unresolved`.

Nomes de membros. Um método, acessor, campo ou assinatura abstrata é gravado qualificado pelo dono — `AuthService.validateToken`, `TokenStore.load`, e o construtor como `Classe.constructor` — porque a captura traz o nó da classe junto com o do membro. É essa a forma que uma âncora de decisão escreve, e é a forma que `symbolKey` compara; o separador é `QUALIFIED_SEPARATOR`. Uma interface contribui só o próprio nome, sem membros: membro de interface é tipo, membro de classe é código que uma mudança quebra. Export default anônimo continua de fora — não tem nome, a âncora nesse caso é o arquivo.

Imports cobrem import_statement, export_statement com source (re-exports), require() via predicado #eq?, `import()` dinâmico e `import x = require()`. Specifiers são deduplicados por arquivo porque a PK de imports é (from_path, specifier).

Três queries, nunca uma por padrão: `matches` percorre a árvore inteira, então uma query por kind pagaria vinte travessias por arquivo. O nome da captura carrega o kind. Declarações e membros são deduplicados por (line, kind, name) — é o kind que distingue um getter do seu setter, que compartilham nome e linha — e `variable` é um kind de fallback que perde para qualquer padrão mais específico no mesmo (line, name), que é como `export const f = () => {}` continua sendo `arrow`. EXTRACTION_VERSION foi para 3 por tudo isso.

Substitui a decisão salva minutos antes na mesma passagem, que descrevia a cobertura nova mas perdeu a regra de nomes qualificados que ela superseded.
