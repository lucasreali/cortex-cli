repoRoot, cortexDir, projectPath, root and startDir were all bare strings. buildRuntime takes a cwd and buildRuntimeAt takes a repo root, and nothing in the type system stopped a caller swapping them. The '.cortex' literal appeared in eight files and the not-initialized guard was written out twice, error message included.

ProjectRoot (src/storage/project-root.ts) owns cortexDir, decisionsDbPath, codeDbPath, isInitialized() and nearest(). findNearestCortexRoot stays as a thin delegate for the MCP registry, which wants the directory string.

On the CLI side withRuntime owns the open-guard-and-dispose that six commands repeated verbatim, and requireInitialized owns the single guard message.
