GemmaProvider and SharedEmbeddingProvider had embedQuery, embedPassages and the empty-input guard character-for-character identical, error string included. The natural fix is an abstract base with a protected abstract embedBatch.

Bun's coverage counts an abstract method — and the abstract class itself — as an uncovered function that no test can ever reach. Verified in isolation: an abstract class with one abstract method and full line coverage reports 50% functions. The suite gates on 100% functions (bunfig.toml), so an abstract base cannot land without weakening the gate.

KindEmbeddingProvider is therefore concrete and takes the transport as a constructor argument; each provider passes an arrow that defers to its own private send method. Referencing `this` inside an arrow in the super() argument list is legal because the arrow is only called later. This shape measures 100%.
