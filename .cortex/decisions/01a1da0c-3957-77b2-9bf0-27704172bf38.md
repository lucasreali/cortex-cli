Decision files arrive through any merged pull request and the hook is global, so a clone could put attacker-chosen text, with keywords picked to match every prompt, in front of the model. Trust is a per-user list (~/.cortex/trusted-projects.json) filled only by cortex init and cortex trust; untrusted projects get a fixed pointer to get_context and no decision text, titles included. Injected text is framed as contributor-written data, never instructions, with provenance and commit. No environment variable relocates the list. Rejected: trusting on first MCP contact (that is exactly how a clone arrives) and refusing suspicious files (doctor notes them instead).
