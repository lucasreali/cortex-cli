The repository had no LICENSE, no `license` field and no statement anywhere, on a public repo that serves install.sh over raw.githubusercontent.com and publishes binaries for seven targets. With no license the default is "all rights reserved": no grant to use, redistribute or vendor the binary, nothing a packager (the Homebrew tap and npm wrapper in docs/distribution.md) or a contributor can accept.

MIT was chosen over Apache-2.0. Both fit the bundled dependency set (Apache-2.0, MIT, BSD-3-Clause, ISC); MIT was picked for being the shorter obligation on downstream packagers, and because the patent grant Apache-2.0 adds buys nothing for a project with no patents. Apache-2.0's own NOTICE ceremony would also have to be repeated per release.

`package.json` keeps `private: true` — that guards against an accidental `npm publish`, and is independent of the license. The binary is a single file with every dependency inside it, so LICENSE ships as a tarball member rather than only living in the repo.
