Any repository on github.com takes a release with its own checksums.txt, so allowing the whole host let an environment variable install a fork's binary. An installed binary now accepts no origin but github.com/lucasreali/cortex-cli, and before installing it asks GitHub's attestation API for the asset digest and requires a SLSA provenance statement from this repository's release.yml at the tag being installed. The Sigstore signature is not re-verified in process — that would bundle a verifier into the single binary — and gh attestation verify remains the cryptographic check. Download limits are enforced while streaming.
