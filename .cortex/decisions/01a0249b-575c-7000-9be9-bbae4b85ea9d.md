`cortex benchmark --write` replaced whatever BENCHMARKS.md it found, and re-stamped the date every run. Two consequences: a file a person wrote by hand was data loss waiting to happen, and a re-run that measured exactly the same corpus still produced a diff, which is how a generated file starts being committed for no reason.

The generated line — "Generated by `cortex benchmark --write` on YYYY-MM-DD with cortex X" — is now the marker and the state. generatedDate() in src/benchmark/report.ts reads it back. A BENCHMARKS.md without it belongs to someone else: --write refuses with exit 1 and says to move it aside, rather than prompting (the command has to stay usable from CI). When the marker is there, the report is rendered once with the date already in the file; if that equals the file byte for byte, nothing is written and the command says it is already current. Only a run whose numbers actually moved takes today's date.

Two other things the report said but the code did not do. The narrowest keyword was chosen by fewest tokens while the prose, and the file count printed beside it, called it the term matching the fewest files; it is now chosen by files, ties broken by cost. The grep baseline was described as tracked files, but git is asked with --cached --others --exclude-standard — everything it would not ignore, which is the working tree a person greps; the prose now says that.

The hit-rate caveat ("the question is the decision's own title, so this is a ceiling on retrieval, not a measurement of it") moved from prose in the markdown into HIT_RATE_CAVEAT on BenchmarkReport, so the terminal table and --json publish it too; report.ts wraps it, since the markdown is otherwise hard-wrapped so a re-run diffs line by line.

An economy with a zero denominator now renders n/a rather than 0.0x, which read as cortex costing infinitely more than the alternative it beats.

Repository reads are batched OPEN_AT_ONCE (32) at a time instead of one Promise.all over every file: EMFILE came back as "empty file" and silently discounted the baseline. A file that could not be read is now named on stderr rather than disappearing into a better number.
